※注意※
・Shift + F4で落ちます。
・スレッドを雑に常時走らせているため、見た目のわりにCPUを使用します。
・"kill.dll"の実行に、"chars/kfm_kll_TEST/kill.dll"という相対パス
  を使用している都合上、フォルダ名を変更したり、フォルダ階層
  が上記の通りになっていない場合には正常に動作しません。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

このキャラクターは、非常にシンプルな超直死体験用のキャラクターです。

デフォルトでは、
・palno = 1 && command = "holddown" で超直死実行
・palno = 2 && command = "holddown" で超直死 + スレッド利用NoKO解除
を行っています。

Const(size.Z.width)に0x1を代入することで超直死が、0x2を代入することで
超直死+NoKO解除がスレッドから実行されるようになっているので、
StateDef -2にある記述を変更して確認してみるのもよいでしょう。

・使用方法
 １．"kfm_kill_TEST"をselect.defに登録する
 ２．kfm_kill_TESTを戦わせる
 ３．任意のタイミングで↓キーを押し、超直死が実行されていることを確認する
 ４．以上
